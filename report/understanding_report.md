# Paperclip Project Understanding Report

## Overview
Paperclip is an open-source orchestration platform for managing teams of AI agents, designed to function like a company with org charts, budgets, and governance. It provides a control plane for managing AI agents from various providers (OpenClaw, Claude Code, Codex, etc.) and coordinates their work toward common business goals.

## Key Features
1. **Agentic Task Manager**: Ticket-based task system with audit trails and verification capabilities
2. **Org Chart for Agents**: Role-based permissions and hierarchical structure for AI agents
3. **Goal Alignment**: Tasks trace back to company mission with full context visibility
4. **Cost Control**: Budget enforcement and cost tracking at multiple scopes
5. **Multi-Company Support**: Complete data isolation for multiple organizations
6. **Governance**: Approval workflows and control mechanisms
7. **Heartbeat Execution**: Scheduled agent wakeups and task processing

## Architecture
Paperclip's architecture consists of multiple interconnected systems:
- Identity & Access Management
- Org Chart & Agents management
- Work & Task System
- Heartbeat Execution engine
- Workspaces & Runtime environment
- Governance & Approvals
- Budget & Cost Control
- Plugins system
- Secrets & Storage
- Activity & Events tracking
- Company Portability features
