- `tsc --noEmit -p ui` reported no diagnostics in the edited files. Other projects' suites were not run (out of scope).

## 7 Evaluation and recommendations
- Overall the shard is healthy: mostly pure-function checks with fixed ISO dates and injected clocks.
- Product finding (no test bent): `nextCronFires` constructs a new `Intl.DateTimeFormat` for every minute iteration (up to about 1M iterations for sparse schedules). Caching the formatter would cut preview cost sharply and remove the need for the 30s test budget. This is a UI performance improvement, not a correctness bug.
- Coverage gaps left open: `issue-change-receipt` timestamp formatting (needs a fixed locale and timezone); `cross-tab-poll` real-timer tick path; `import-preflight` exact boundary at `INLINE_IMPORT_MAX_BYTES`.
- Suggest splitting `inbox.test.ts` and `issue-chat-messages.test.ts` by concern, and giving `keyboardShortcuts` a shared `baseArgs` helper as its first describe already does.
