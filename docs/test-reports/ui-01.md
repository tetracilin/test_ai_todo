All 45 files were read in full and checked against their production modules (adapter metadata and registry, api clients, server route table, App route table, component sources). ## 7 Evaluation and recommendations

Product findings:
1. `ui/src/api/issues.ts` `stopActiveRun` calls `POST /issues/:id/active-run/stop`; the server has only `GET /issues/:issueId/active-run` (server/src/routes/agents.ts) and `POST /heartbeat-runs/:runId/cancel`. Either implement the route or delete the method, its `StopIssueActiveRunResponse` type and the test. Needs a product decision; the test was not altered.

Coverage gaps worth a cheap follow-up: enabled path of `useDisabledAdaptersSync`; Hermes Gateway config in create mode with edits; Blocked inbox retry button; error propagation in `attentionApi` and `artifactsApi`.

Maintainability: extract the repeated jsdom `CSSStyleSheet.insertRule` patch (4 App.* tests) and the `act`/`flushReact` helpers into a shared test util. Prefer behavioural route assertions over `App.tsx?raw` greps.
