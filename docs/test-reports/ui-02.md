## 2 Summary

All 45 files were read completely and checked against the component or helper source they import. All subjects still exist in the fork and assertions match current behaviour; no upstream-only behaviour or stale default was found. Fork-relevant checks: `ConfigureBuiltInAgentModal` already treats `hermes_gateway` as a non-model adapter and its tests state the adapter types they use (`codex_local`, `claude_local`, `process`) rather than depend on a registry default; `CompanySettingsSidebar` expectations match the current sidebar.

Verdicts: VALID 24, VALID_WITH_NOTES 15, REWRITTEN 6, OBSOLETE_REMOVED 0, NEEDS_DECISION 0.

Six files were edited to fix assertions that could not fail (V2) or global state that leaked when a test failed (V4). No test case was deleted or skipped and no production code was touched. After the edits the whole shard passes: 45 files, 327 tests.

## 3 Variances

* The host is Windows 11. All ui jsdom suites ran natively with no ENV failures, so no ENV variance applies.
* Radix popover/menu tests depend on jsdom pointer-event polyfills and fake timers; they passed on every run here but flake rate was not measured over repeated runs.
* Tailwind class-string assertions (ChatComposer, EntityRow, CommentThread) were checked against component source only, not rendered CSS.
* `pnpm check:token-gates` was not run (test files are outside its scope).

## 7 Evaluation and recommendations

* Product findings: none. No suspected production bug.
* Coverage gaps (V7, report only): CommandPalette has no test for the API-error path; BuiltInAgentGate does not test a failed `list` request; DiscordSettingsPanel has no error-path test for `createLinkCode`; FileTree has no ArrowLeft collapse test.
* Recommend extracting the repeated `flushReact` / `waitForAssertion` helpers into one shared, time-bounded test util (as done for CompanySettings in #161) instead of iteration-bounded loops.
* Recommend a real `QueryClient` in DecisionResolver and IssuePropertiesDocumentAnnotations instead of module-level react-query stubs, so hook signature changes surface.
