## What this release is

K1→K19 of the T3 fork program: fork `paperclipai/paperclip` as the new baseline,
port the scheduling features from the legacy Gemini AI-todo app, cut Google from
the runtime, route **all** AI runs through the local Hermes gateway, and land a
deployable production stack with CI/CD. 3,794 commits of fork delta vs `main`.

## Ops notes for power users

```sh
# Health
curl -s http://127.0.0.1:3100/api/health   # status ok + commit + databaseBackup.status

# Restart (30s grace — embedded PG no longer applies; compose-managed)
docker compose --env-file deploy-prod/runtime.env -f deploy-prod/compose.yaml restart paperclip

# Manual backup / restore
docker exec t3-prod-db-1 pg_dump -U paperclip paperclip > manual-$(date -u +%Y%m%dT%H%M%SZ).sql
cat <dump>.sql | docker exec -i t3-prod-db-1 psql -U paperclip -d paperclip

# Hermes gateway relays MUST be up (expect TWO socat binds + hermes)
ss -tlnp | grep 8642

# Guard rails
bash /usr/local/bin/paperclip-healthcheck ; echo $?            # expect 0
docker exec paperclip node /paperclip/scripts/paperclip-circuit-breaker.cjs ; echo $?  # expect 0
```

Gateway error codes (runbook Part C): `hermes_gateway_api_key_missing` ·
`plain_http_remote_denied` (needs `dangerouslyAllowInsecureRemoteHttp=true`) ·
`connect_failed` (relay down) · `auth_failed` (key ≠ `API_SERVER_KEY`).

⚠ **If `API_SERVER_KEY` rotates**, every `hermes_gateway` agent's stored secret
(`company_secrets` binding) must be re-synced or all runs fail `auth_failed`.

Circuit breaker: ≥5 consecutive failed runs in 90 min → pauses agent + writes
`/root/paperclip-circuit-breaker-ALERT.md`. Resume is deliberately manual.
