# Agent Artifacts and Work Products

## Artifact Management

Paperclip follows a structured approach for managing agent-generated artifacts:

1. **Inspectable Artifacts**: All user-visible deliverables must be uploaded through the Paperclip API using `paperclip-upload-artifact.sh` script.
2. **Workspace Files**: Important files that remain workspace-only should be tracked as work products with `metadata.resourceRef.kind: "workspace_file"`.
3. **Artifact References**: Generated files should be linked in issue comments with their full path and access metadata.

## Artifact Upload Process

1. Use the dedicated script for artifact uploads:
```sh
skills/paperclip/scripts/paperclip-upload-artifact.sh <file_path> <artifact_name>
```

2. The script handles:
- File upload to Paperclip API
- Artifact metadata generation
- Work product creation
- Issue comment linking

## Artifact Verification

All artifacts must be verified against these criteria:

1. Accessibility: Can be retrieved through the Paperclip API
2. Metadata completeness: Contains all required metadata fields
3. Issue linkage: Properly referenced in the associated issue
4. Format compliance: Follows repository format standards

## Artifact Lifecycle

1. Creation: Generated by agents during task execution
2. Review: Linked to issues for human verification
3. Approval: Marked as accepted or requiring revision
4. Archival: Moved to long-term storage when appropriate

## Artifact Types

| Type | Description | Storage Location |
|------|-------------|----------------|
| Code | Source code files | `artifacts/code/` |
| Docs | Documentation files | `artifacts/docs/` |
| Media | Images/videos | `artifacts/media/` |
| Data | Data files | `artifacts/data/` |
| Logs | Execution logs | `artifacts/logs/` |

## Artifact Metadata

All artifacts must include these metadata fields:

```json
{
  "artifactId": "uuid",
  "contentType": "mime-type",
  "byteSize": "number",
  "sha256": "hash",
  "originalFilename": "string",
  "createdByAgentId": "uuid",
  "createdByUserId": "uuid",
  "contentPath": "path",
  "openPath": "path",
  "downloadPath": "path"
}
